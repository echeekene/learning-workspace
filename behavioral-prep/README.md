# Behavioral Prep

Answers use STAR: Situation, Task, Action, Result.

## Questions to prepare

- [ ] Tell me about yourself
- [ ] Why this company and this role
- [ ] A time I led a team
- [ ] A time I handled a difficult customer or stakeholder
- [ ] A time I failed and what I learned
- [ ] A time I learned something new quickly
- [ ] A conflict with a coworker
- [ ] A time I improved a process

## Story bank

Write each story once in its own file and reuse it across questions.
